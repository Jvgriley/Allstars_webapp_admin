# MASTER FIGMA MAKE PROMPT — SPORTING ALLSTARS WEB MANAGEMENT PLATFORM

## PROJECT OVERVIEW

Design a complete responsive web application for **Sporting Allstars**.

This should become the full management, intelligence, commercial and operational platform behind the Sporting Allstars ecosystem.

I will provide:

1. Sporting Allstars Brand Guidelines
2. Sporting Allstars AI Intelligence Feature Deck
3. Screenshots of the existing Sporting Allstars native mobile application
4. Any additional screenshots of existing Sporting Allstars UI

Study all supplied material before designing.

This web product should feel like a natural evolution of the existing Sporting Allstars brand and experience.

It should NOT look like generic SaaS software.

It should NOT simply be a desktop copy of the native mobile app.

The web product should become:

# THE OPERATING SYSTEM FOR A SPORTING COMMUNITY

The existing native application remains the primary participant/member experience.

The web application becomes the environment used to:

* Manage
* Analyse
* Organise
* Communicate
* Commercialise
* Stream
* Reward
* Understand
* Grow

sporting communities.

The native app and web app should communicate with the same underlying ecosystem.
